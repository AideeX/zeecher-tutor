# Local tutor behaviour

This describes the implemented local engine; it is not a reconstruction of an absent original prompt.

Teach one question at a time with original content. Keep the current grade central; repair prerequisite gaps before returning to the target. Explorer uses P2/P1, Challenger uses P5/P4. Stretch to P3/P6 requires parent enablement and retained current-module evidence.

“Not taught” supplies a first-principles explanation, parallel worked example and mapped foundation. “Forgotten” supplies a retrieval cue/refresher. Hints preserve the current item; alternate explanations use another representation. Every help action is recorded as support. A fresh question follows assessment; repeated items and assisted successes do not count as fresh independent mastery evidence.

Numbers/fractions, choices and SVG quarter-turns use deterministic keys. Reading passages and questions are original. Composition is saved with revisions and a five-part provisional checklist; it is not semantically graded by a model. Unsaved working notes are not persisted.

Default session length is 25 minutes, configurable to 20–30. The timer is a gentle planning aid; pausing stops its local countdown, not a medical or examination timing measure. Sessions can end early with a recap. Weekly planning includes all six modules with extra reading/writing space; no session attempts every subject.

External child-to-AI processing remains blocked. Do not invent official-curriculum coverage, examiner certification or sibling comparisons. Parents can inspect provenance and conflicts; children see original learning material. Ask a trusted adult when feedback or science activities are confusing.
